把SSTKG中的部分模块融入到EpiLLM中，提升预测准确性：

（1）在EpiLLM 的疫情分支中引入 SSTKG 的影响力矩阵替代原始邻接矩阵，便于验证基础融合效果。

（2）多步预测约束：基于 SSTKG 影响力修正误差 针对 EpiLLM 多步预测的误差累积问题，引入 SSTKG 的动态输入嵌入作为约束： 每一步生成疫情和流动性预测后，用 SSTKG 的公式验证实体间的影响力是否符合历史规律。 对偏离过大的预测值进行修正，保证生成的时空数据满足 "高影响力区域的变化会显著影响关联区域" 的基本规律。 

（3）可解释性增强：构建量化传播图谱 融合 SSTKG 的影响力后，可生成区域疫情传播量化图谱，直观展示每个区域的主要传播源和影响范围： 对每个目标区域，按影响力大小排序其关联区域，识别高风险传播源。 通过时间维度的影响力变化，分析疫情传播的动态演化规律。
